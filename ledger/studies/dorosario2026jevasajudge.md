# dorosario2026jevasajudge: Jev-as-a-Judge for RAG Claim Verification (Do Rosario, Atef)

## Identification

- arXiv 2610.20634v1, cs.CL, 30 Sep 2026 (header). Full text: fulltext/2610.20634.html and .txt (HTML retrieved 2026-10-28).
- Authors: Alden Do Rosario, Kirollos Atef. Affiliation: CustomGPT.ai (title block). Affiliation type: industry. The first author founded and leads CustomGPT.ai, whose product includes claim verification; the second author works there. CustomGPT.ai is a paying API customer of both vendors, with no discount or early access (Section 12.1).

## Task and data

- Binary grounded claim verification for RAG: does the evidence support the claim, labels supported / not_supported (Section 3).
- Data: development split of LLM-AggreFact at a pinned revision; 495 claims, equal strata of 45 from each of 11 component datasets; 297 supported, 198 unsupported (Section 5, Table 3). The sample is the set of claims an earlier exploratory Jev pass answered; the example-ID list is released but regenerated by no code (Section 5, Appendix E).
- Test split never read (Section 5, "Split discipline").
- Test-set exposure: public benchmark public for years; authors state neither system can be assumed uncontaminated (Section 5).

## Decision models and comparators

- Jev: jev-1.13.0 (TypeSafe), version pinned on every call; SDK default alias avoided (Section 4). Typed enum answer plus native probability of supported; the scalar "confidence" it also returns is logged and never reported. Response validity 100.0%. Mean tokens 1,139 in / 35.4 out (Table 2).
- Comparator: gpt-6-astra (frontier LLM), enumerated token, no tools, provider-default temperature, two reasoning efforts (low primary, high), caps 256 vs 4096 completion tokens. Provides no logprobs (API returns 400), so probability provenance "none" (Sections 3, 4, 8.2). Mean tokens 843 / 10.0 (low), 843 / 45.3 (high).
- Excluded arm: MiniCheck-Flan-T5-Large, run and excluded because the authors' port scored far below every other row (Section 4, Appendix E).
- Cascade: Jev first; accept if max(p, 1-p) clears a threshold, else escalate to Astra's stored verdict. Offline replay from locked prediction files (Section 5).

## Tuning-budget parity

- Same semantic instructions to both systems. A pre-publication audit found Jev's criteria named wrong entities as grounds for not_supported while the frontier prompt did not (asymmetry favouring Jev); the trigger was added and both frontier configurations were re-run; all frontier numbers come from corrected runs (Section 4, "Prompt parity"). Prompts in Appendix B.
- Both efforts run under one prompt forbidding reasoning in the output; no provider-default or reasoning-inviting prompt was run (Sections 4, 12).
- Cascade thresholds chosen by 200 repeats of 5-fold stratified cross-fitting; in-sample sweep reported separately as optimistic (Sections 9.2, 10).

## Reference labels

- Gold labels are the original LLM-AggreFact human annotator labels (Table 3 caption: "as labelled by the original annotators"). Coded human_adjudicated at the aggregate level (the benchmark consolidates human-labelled datasets; adjudication detail not given in the paper).

## n, sampling design, intervals

- n = 495 (198 gold-unsupported). Stratified by dataset (45 each). Intervals: 95% paired stratified bootstrap, 10000 resamples, stratified by dataset; exact McNemar; Holm-Bonferroni over 13 McNemar tests (Section 5). The cascade bracket is a percentile interval over 200 cross-fitting repeats, not a CI (Table 8 caption).
- Thinnest minority class is 4 claims (RAGTruth); authors read false-verification only at the aggregate (Section 7.4).

## Results used in the ledger

- Macro balanced accuracy Jev 73.27 [68.5, 77.9] vs Astra low 73.83 [68.8, 78.8] vs Astra high 74.11 [69.1, 79.0] (Table 1); paired difference -0.56, 95% CI [-5.6, 4.5], McNemar p = 0.49 (Section 6, Table 4). No equivalence claimed; no equivalence margin preregistered (Section 6.3).
- Raw accuracy Jev 79.8 vs 78.4; macro F1 79.1 vs 78.2; MCC 0.582 vs 0.581 (Table 5). Per dataset, Jev higher on 6, Astra on 5 (Section 7.3, Table 11).
- Disagreement on 15.2% of claims; Jev right and Astra wrong 41, reverse 34, neither 66 (Table 6).
- False verification: Jev 23.23% vs Astra 14.14%, gap 9.1 points, bootstrap [4.55, 13.64], McNemar p = 0.000534 (0.005 Holm) (Section 7.2).
- Cost and latency: $0.04786 vs $8.93 per 1k claims, 187-fold; high effort $10.70 (224-fold). Modelled from measured token counts and the archived price snapshot configs/pricing_2026-09-20.yaml, standard tier, no caching; Jev output tokens billed at zero by its provider (Sections 4, 5, Table 2). Re-pricing output tokens at the input rate gives 181-fold. Latency not measured (Section 5, Appendix E).
- Calibration: native probability AUROC vs gold 0.868 (AUPRC 0.893); selective AUROC 0.722; Brier 0.153 (constant forecast 0.250); ECE 0.099 over ten equal-frequency bins, 0.107 at fifteen; NLL 1.133, 62% of it from 10 certain-and-wrong claims charged at a provisional clipping constant (Section 8.1). Equal-mass binning used because probabilities pile up at 0 and 1. No post-hoc recalibration. Under-confident at low probabilities, over-confident in a narrow band near the top.
- Confidence gating of Jev alone: coverage 35.2% gives verified precision 97.1% and FVR 2.1%, macro over 9 of 11 datasets (Table 7).
- Cascade: cross-fitted 74.10 [72.1, 75.8] at $2.92 per 1k claims, 29.9% escalated, vs Astra 73.83 at $8.93 (3.06-fold lower cost); cascade minus Astra 0.27 [-3.85, 4.15], median McNemar p 0.20, below Astra in 68 of 200 repeats (Section 9.3). Cascade FVR 19.22% vs 14.14% (+5.08, CI [1.52, 9.09], Holm p = 0.057) and vs Astra high +6.09 [2.53, 10.10] (Holm p = 0.005) (Table 9). Cascade vs Jev alone: +0.83 [-3.36, 4.86] for 61-fold the cost (Section 9.4). Matched random escalation (30.9%) 73.36 at $2.81 vs confidence gate 74.01 at $2.94; random minus Astra -0.47 [-5.44, 4.41] (Section 9.5, Table 10). In-sample threshold 75.82 (17.2% escalated, $1.62) vs out-of-fold 74.10 (Section 10). Oracle routing 82.91 at 20.2% escalation, $1.60 (Table 8). Chosen threshold bimodal: 0.80 chosen 669 of 1000 fits, top grid value 253 (Section 10.1).
- Run-to-run: an earlier Jev pass over the same IDs scored 72.44 and flipped 7 verdicts; the later 73.27 pass is reported (Sections 6.1, 12).

## Authors' own limitations (Section 12, Appendix E)

Indistinguishable is not equivalent; one draw of fold assignment; sample is a released list, not a rerunnable draw; offline replay with no second hop in cost; modelled costs from list prices; each arm run once; no controlled latency; contamination not ruled out; one frontier family; MiniCheck exclusion; calibration comparison has one participant; harness built with AI coding assistance; no analysis decision was preregistered.
