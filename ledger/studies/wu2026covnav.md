# wu2026covnav — CovNav: Conformal Prediction-Guided Adaptive Inference for Object Goal Navigation

arXiv:2610.27677v1 [cs.RO], 20 Oct 2026 (version from the HTML header). Full text: fulltext/2610.27677.html and .txt. Method paper for zero-shot object goal navigation: a local Qwen3-8B answers a Yes/No object-pair question in fast mode, a split-conformal gate on the Yes/No probabilities decides whether to re-ask the same model with thinking enabled, and the resulting scores feed a semantic value map that picks exploration frontiers (Sec III-B, III-D). Included because the fast stage returns normalized Yes/No probabilities from one forward pass without text generation (Sec III-D.1, Eq. 1), which meets the protocol's definition of a typed probabilistic decision model; the slow fallback does not remove this component; navigation success is measured against baselines (Sec IV).

## Task and data
Zero-shot ObjectNav in the Habitat simulator under the Habitat Challenge 2022 and VLFM task setting, 500-step budget, success when Stop is issued within a geodesic success threshold of a target instance, "typically set to 1.0 m" (Sec III-A, IV-A). Gibson (5 scenes, 1,000 episodes), HM3D v1 (20 scenes, 2,000 episodes) and HM3D v2 (36 scenes, 1,000 episodes), targets from 6 indoor categories (Sec IV-A). Metrics are Success Rate and SPL (Sec IV-A, Eq. 5, 6). Ablations use 100 randomly sampled episodes per dataset, with SR and SPL computed per target category and averaged over the six categories (Sec IV-C). A real-robot demonstration on a TurtleBot 4 with an RTX 3080 laptop covers three multi-room indoor environments and reports one representative 73-step episode, with no success counts (Sec V, Fig. 6).

## Decision models evaluated
Fast mode: Qwen3-8B, prompted "Is it highly likely to find a {goal_name} close to the {landmark} in the same room? Answer with 'Yes' or 'No'.", one forward pass, logits for Yes and No turned into a score c by temperature scaling with T = 10 (Sec III-D.1, Eq. 1; Sec IV-A). The backbone is printed as Qwen3-8B (Sec III-D.1, III-D.3, IV-A), as Qwen3-8B-FP8 in Table VI and for the robot (Table VI, Sec V); the paper does not say whether the simulation runs used FP8; no checkpoint or revision is given. Slow mode: the same model with the enable_thinking flag on, generating a chain-of-thought trace before the answer, so it is not a single-pass typed decision; the paper does not say how the slow-mode score is read out (Sec III-D.3). The Qwen3-8B query runs only for objects outside a static relation matrix that GPT-5 pre-computes offline for the 80 COCO categories (Sec III-D.1, IV-A); every navigation result, including Fast-Only and Slow-Only, therefore measures the hybrid system with this matrix. Gate: split conformal prediction with nonconformity 1 − P̂(y|x); a singleton set keeps the fast answer, an empty or two-label set triggers slow mode (Sec III-D.2, III-D.3, Eq. 2). α = 0.5 (Sec IV-A); by Eq. 3 the stated guarantee at that α is coverage of at least 0.5 (Sec III-D.2, Eq. 3). Jev is cited only as an analogue for casting queries as structured decisions (Abstract; Sec I; refs 13, 14); no Jev system is run and no Jev number appears.

## Comparators and tuning parity
Table I baselines: L3MVN, VLFM, GAMap and ApexNav (Sec IV-B, Table I). The paper does not say whether these were re-run on the same episodes or copied from their papers, and gives no versions or settings for them (Sec IV-B). Internal variants on the same 100 episodes per dataset: Fast-Only, Slow-Only and Random Switch (Sec IV-C.1, Table II); α of 0.8, 0.5, 0.2 (Table III); fixed raw-probability thresholds 0.8, 0.5, 0.2 without CP (Table IV); component removals (Table V). T = 10 and α = 0.5 are stated with no separate selection data; the α and threshold sensitivity runs use the same ablation episodes on which the default is reported (Sec IV-A, IV-C.2, IV-C.3). α = 0.5 has the highest SR of the three α values only on HM3D v1 (62.8); α = 0.8 is higher on Gibson (82.9) and HM3D v2 (79.2), and α = 0.2 is higher on Gibson (80.1 against 79.5) (Table III), while the text describes α = 0.2 as giving "consistent performance degradation across all datasets" (Sec IV-C.2). Removing confidence decay gives 80.2 / 46.8 on Gibson against 79.5 / 43.7 for the full system, while the text calls the component "equally vital" (Sec IV-C.4, Table V). The calibration viewpoints come from the Matterport3D training split (Sec III-D.4), and the CP guarantee assumes calibration data exchangeable with the test data (Sec III-D.2).

## Headline numbers and their sources
Table I (full benchmarks): CovNav SR 82.4 / 60.4 / 77.9 and SPL 48.6 / 33.1 / 40.2 on Gibson / HM3D v1 / HM3D v2; ApexNav SR 59.6 / 76.2 on HM3D v1 / v2 with no Gibson value; GAMap SR 85.7 on Gibson (Table I). The abstract's margins of 0.8 and 1.7 points are CovNav over ApexNav on HM3D v1 and v2 (Abstract; Sec IV-B). On Gibson CovNav is below GAMap and VLFM is 81.8 (Table I). Table I reports CovNav SR 77.9 on HM3D v2; Table II, on the 100-episode category-averaged protocol, reports 78.5 (Sec IV-C; Tables I, II). Table II: Fast-Only 72.5 / 51.5 / 69.8, Slow-Only 83.1 / 64.2 / 82.5, Random Switch 76.8 / 57.1 / 75.4, CovNav 79.5 / 62.8 / 78.5 SR (Table II). The conclusion's "matching the navigation performance of always using the slow deliberative mode" is the authors' wording; CovNav is below Slow-Only on all three datasets in Table II (Sec VI; Table II).

## Reference labels
Navigation outcomes are task outcomes from the simulator success criterion (Sec III-A, IV-A), coded task_outcome. The conformal calibration set of 1,200 object-pair queries is synthetic: GPT-5 lists objects in 50 Matterport3D training-split viewpoints per room type for four room types, lists are manually screened, objects above a 20% frequency threshold are kept, same-room pairs are labelled Yes and cross-room pairs No (Sec III-D.4, IV-A). The per-query accuracy of the fast decision against any label is never reported.

## n and intervals
Table I episode counts scored are not stated; dataset sizes are 1,000 / 2,000 / 1,000 (Sec IV-A). Ablations: 100 episodes per dataset (Sec IV-C). No seeds, run counts, standard deviations or intervals are reported for any table (Tables I to VII).

## Test-data exposure
Gibson and HM3D episodes follow the Habitat Challenge 2022 setting cited by the paper [50] (Sec IV-A), coded public-pre-2026. The decision model sees generated object-pair questions, not the episodes; no contamination check is reported (Sec III-D.1, IV).

## Cost and latency
Hardware: NVIDIA RTX 4090D (24 GB), AMD Ryzen 9 7950X, 64 GB RAM for all simulated runs, both modes local (Sec IV-A). Table II time: Fast-Only 0.63 s, Slow-Only 3.40 s, Random Switch 1.25 s, CovNav 0.72 s; the Random Switch and CovNav times are estimated from the Table VI module latencies, not measured (Sec IV-C.1, Table II). Table VI module latencies: fast mode 180 ms, slow mode 2400 ms, CovNav average 680 ms, total VRAM 22.6 GB; the printed 3.5 times speedup is 680 ms against the slow mode (Sec IV-D, Table VI). The two CovNav latency figures differ (0.72 s in Table II, 680 ms in Table VI), and the conclusion describes the reduction as "nearly one-third" (Tables II, VI; Sec VI). No monetary cost is reported.

## Calibration
No empirical coverage, ECE, Brier score or reliability diagram is reported (Sec IV-E). Sec IV-E shows only named pairs from Figure 5, for example (Toilet, Laptop) 0.60 in fast mode and 0.25 after slow mode, and (Bed, Chair) 0.49 to 0.75 (Sec IV-E, Fig. 5). Post-hoc: fixed T = 10 on the Yes/No logits and the split-conformal threshold (Sec IV-A).

## Cascade or escalation
Slow mode on 12.4% of queries at α = 0.5; the denominator (open-set object queries to the local model, or all relation lookups) is not defined (Abstract; Table II). SR within 1.4 points of Slow-Only on HM3D v1 (62.8 against 64.2) (Sec IV-C.1). α = 0.8 switches on 22.4% and α = 0.2 on 8.2% (Table III). A fixed threshold of 0.5 switches on 10.1% with HM3D v1 SR 60.9; a fixed threshold of 0.8 switches on 42.7% and beats CovNav on Gibson (82.0) and HM3D v2 (80.4) but not HM3D v1 (54.2) (Table IV). Random Switch at 53.0% scores below CovNav on all three datasets (Table II).

## Option-name, cardinality, robustness tests
None. The answer space is fixed at Yes/No and one prompt is used (Sec III-D.1). Component ablations: without the CP-calibrated value SR falls to 52.5 / 41.2 / 66.8, without confidence decay 80.2 / 51.3 / 65.4, without open-set perception 68.4 / 54.6 / 69.5 (Table V). Inference failures (fast mode confidently wrong or slow mode hallucinating) are 19.3%, 19.2% and 21.2% of failed episodes on Gibson, HM3D v1 and HM3D v2 (Sec IV-F, Table VII).

## Authors' limitations
No separate limitations section; the conclusion states none (Sec VI). The failure analysis attributes most failures to perception (45% to 52%) and navigation traps (28% to 35%), with inference failures 19% to 21% (Sec IV-F, Table VII). Table II times for Random Switch and CovNav are estimates (Sec IV-C.1).
