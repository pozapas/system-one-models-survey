# stambler2026pyes — P(Yes): 15x Improvements via Test-Time Scaling of Decision Models

arXiv:2610.25474 (version not stated on the PDF; dated October 2026, listed 18 Oct 2026). Full text: fulltext/2610.25474.pdf (arXiv HTML was not available) and .txt (pdftotext). Code: github.com/tear-labs/pyes-search at commit 0e858f2 (title page, Reproducibility).

## Authors and affiliation
Lev Stambler (Tear Labs; University of Maryland, College Park) (title page). Affiliation type: mixed (single author with a company and a university affiliation). AI tools helped write code and adapt a blog post (Acknowledgments).

## Task and data
Test-time search over complete answers to multi-blank tasks: a frozen decision model is shown a complete proposed answer plus a fixed verification question, its probability of "Yes" is the score, and search (random switches, belief-propagation steps with an OSD shortlist, coupled flips) looks for higher-scoring answers; the model never generates text and weights never change (Sec 1 to 3). Sets: 128 synthetic logic puzzles (seating puzzles and 4x4 Latin squares, 654 blanks), 68 dev forms (selected by earlier experiments, "not a clean test"), 68 held-out forms (written for this project, untouched until 2026-09-23 but used repeatedly since) (Sec 4.1, footnote 1). Transfer study: first 47 logic puzzles completed by all four open search models (Sec 4.4). JevBench held-out families (82 single-blank tasks) used once for reference (Sec 5).

## Decision models evaluated
Jev (typesafe/jev-1.13), hosted, public decisions API only, probabilities rounded to two decimals, API not fully deterministic, run dates not reported (Sec 4.4). StartLux Instant v1.1, Perplexity Decider v1.1 (released temperature calibration kept), Cloudflare Clef, all 27B frozen; StartLux AutoThink as a reasoning reference (Sec 4.4, Fig 5, Table 3). Controls: Qwen3.8-27B (Qwen/Qwen3.8-27B@1d4bf0f) and Qwen3.5-9B (@c202236) read through Yes/No next-token logits, BF16, one B200 (Sec 4.1, Reproducibility). Every checkpoint keeps its native inference format and calibration (Sec 4.4).

## Comparators and tuning parity
Same search arms, seeds (three) and cap of 256 additional complete-assignment evaluations for every model in the 47-puzzle study; random edits as a control; the author notes random edits stop early (about 26 extra evaluations for StartLux vs 201 for BP) so no matched-compute advantage over random search is established (Sec 4.4). JEV out-of-the-box numbers are reference points, not equal-compute comparisons because its internal compute is unknown (Sec 5, Table 5 caption).

## Reference labels
Synthetic gold solutions for puzzles; form labels written by the author except 41 SpreadsheetBench-derived fills, not independently validated (Sec 7, App. A).

## n and intervals
128 puzzles, 68 + 68 forms, 47 transfer puzzles. Single run per setting except the transfer study (three seeds averaged). Bootstrap 95% intervals only on the transfer gains (Table 4, Sec 4.4); JEV exact-correctness gain 48.2 points (95% CI 33.3 to 62.4).

## Test-data exposure
Puzzles are generated by the published code (new/synthetic). Dev forms had informed development; held-out forms reused as a confirmation set. SpreadsheetBench portion is public. Jev's held-out-form number comes from an earlier API run on the same tasks (Sec 7).

## Cost and latency
Qwen3.8-27B at largest budget about 217 NFE and 1.8 s per puzzle on one B200 (Sec 5). Instant with search 12.9 s per puzzle vs AutoThink 25.6 s, BF16 on one B200, reference runner not optimized serving (Sec 4.4). Jev wall-clock not compared with B200 times. No monetary cost.

## Calibration
The Yes score is explicitly not a calibrated probability of correctness and is used only to rank answers (Sec 2, 7). No ECE or Brier. Perplexity Decider keeps its released temperature calibration.

## Cascade or escalation
Search is the escalation: native decisions initialise the search and extra evaluations are spent on alternative assignments. Jev rises from 9 to 31.7 of 47 exactly correct (Table 3). Exhaustive scoring on small tasks separates score errors from search errors (Table 1: the 27B best-scoring answer is exactly correct on 41.2% of 51 small puzzles).

## Option-name, cardinality, robustness tests
Candidate sets per blank vary; exhaustive check up to 2,048 assignments. Jev API non-determinism noted. No option-name or language test.

## Code and data availability
Code, puzzle generator and form files public; the unpublished experiment and appendix prompt-rewriting results are not part of the published code (Reproducibility).

## Authors' limitations (Sec 7)
Small sets, mostly single runs, no variation estimate; form labels not independently validated; exhaustive evaluation limited to at most 2,048 assignments; pairwise BP misses higher-order interactions and cost grows quadratically; score can prefer a wrong answer; Jev searched only on the 47 transfer puzzles; Jev held-out-forms result from an earlier API run.
