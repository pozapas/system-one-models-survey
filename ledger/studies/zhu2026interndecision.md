# zhu2026interndecision — Intern-Decision: Efficient Multimodal Decision Making with Autoregressive Masked Language Modeling

arXiv:2610.22131v1 [cs.CL], 15 Oct 2026. HTML retrieved 2026-10-28 from https://arxiv.org/html/2610.22131 (fulltext/2610.22131.html, .txt). Coder: batch V16.

## Authors and affiliation

Tong Zhu, Zhe Xu, Zefeng He, Yunkai Chai, Xuyang Hu, Dehong Zheng, Yun Luo, Yafu Li, Qi Zhang, Yu Cheng (corresponding). Shanghai AI Lab (all), with Shanghai Jiao Tong University, Fudan University and Nanyang Technological University as secondary affiliations (title block). Affiliation type: academic (non-profit research laboratory with university co-affiliations). The authors build and evaluate their own model (own-model paper), so the comparison against Jev is not independent of the developers.

## Task and data

Multimodal typed decisions (choice, Boolean "noul", ordinal score) answered in one causal forward pass using the Qwen3.5 backbone's native LM head, placeholder-per-field JSON skeleton (§3). Evaluation has four parts. (1) Seven accuracy suites (Table 2): Jevbench-Easy 48, Original 72, Hard 111 (public subset, 231 items, excludes private items and the judge tier), Typed Decision 400 records / 2,000 fields, ToolACE 310, AG News 7,600, WildJailBreak 2,210; 12,351 decisions in total; headline is an unweighted mean of suite accuracies (§5.1). (2) Brier and ECE (10 equal-width bins) on the 111 Hard items only (§5.1, Table 4, Fig. 4). (3) Latency on a fixed 289-token, three-field request (§5.3, Table 5). (4) A 96-case known-distribution pilot (24 mechanism families x 2 settings x 2 option orders, so 48 paired settings, §4.2) with exact rational reference distributions, and (5) a single-operating-point confidence handoff on Hard to Atria-Dawn-Preview (§5.5). Section 6 gives qualitative game, CAPTCHA and browser demonstrations, explicitly not benchmarks.

## Decision models evaluated and exact versions

- Intern-Decision-0.8B, -2B, -4B: Qwen3.5-0.8B/2B/4B backbones, hf-156 checkpoints, objective revision masked-next-token-v4, repo git revision 2f815802058b, 2 epochs / 156 updates, lr 2e-6, vision tower and projector frozen (App. A, Table 9). Temperatures 2.747761 / 2.100509 / 1.992418 fitted post hoc on separate calibration records (Table 4, Table 8).
- Jev v1.13.0 (abstract, §5.4); API probability map used. Latency for Jev measured under conditions the authors say are not fully documented (Table 5 caption).
- Laya, SemIf-OpenJev, Kev, JevK5: versions not reported (Table 3 lists names only).
- Atria-Dawn-Preview (InternLM) as the larger handoff model; version not reported.

## Comparators and tuning-budget parity

Baselines are run with "reported/default" settings; Table 4 caption says "Intern-Decision uses separately fitted temperatures; baseline probabilities use their reported/default settings. Temperatures are not comparably refitted for every baseline." Kev has T=2.962195 and JevK5 T=1.532 listed, SemIf 1.0. Intern-Decision is fine-tuned on a 17,880-sample corpus that includes public task distributions equal to evaluation sources (AG News, ToolACE, Typed Decisions, WildGuardMix/WildJailbreak) (Table 1, App. B); the paper says test bundles are separate from internal partitions (App. B). Baselines are not fine-tuned on these sources. Parity: asymmetric (tuned vs as-is). External-baseline adapters and historical responses are not released (App. A).

## Reference labels

Accuracy suites use upstream benchmark labels (Jevbench, AG News, ToolACE, Typed Decision, WildJailBreak); the paper does not describe how Jevbench or Typed Decision test labels were made (typed-decisions "references were generated by the project", App. B, applies to training use). Coded `administrative_field` as the closest schema value; the origin of Jevbench gold labels is unspecified in the paper. Training teacher for synthetic text: deepseek-v4.1-flash (§4.1). Known-distribution pilot uses exact rational-arithmetic references (§4.2), coded `synthetic`.

## n, sampling design, intervals

n as in Table 2. No confidence intervals or bootstrap anywhere; no bin-level uncertainty (§5.2). Pilot has 48 paired settings, not 96 independent trials (§4.2). Suite average is unweighted, not pooled (§5.1). One Jev reliability bin holds a single item (§5.2). Latency: no repetition count, batch size or warm-up reported (§5.3).

## Test-set exposure

"Public Jevbench has informed development and should be treated as a diagnostic, not independent held-out generalization evidence" (§5.1). AG News, ToolACE, WildJailbreak and Typed Decisions are public pre-2026 datasets and also training sources. Pilot is generated after the fact; exact-content check against temperature-fitting records found no overlap, semantic overlap not excluded (§4.2). Jev's own training exposure unknowable.

## Cost and latency

RTX 4090, BF16, SDPA, native HF backend, Transformers 5.14.1, flash-linear-attention 0.4.2. Mean latency Jev 109.70 ms, 0.8B 33.98, 2B 33.28, 4B 44.16; mean ratios 3.23x, 3.30x, 2.48x (Table 5). Handoff time 140.16 s estimated vs Atria-only 300.03 s measured (Table 7). No dollar cost reported.

## Calibration

Hard-item Brier/ECE (Table 4): Jev 0.358420 / 0.094685; 4B 0.346762 / 0.065267 (uncalibrated ECE 0.132613, §5.2); JevK5 has lowest ECE 0.046672. Temperature scaling only; no isotonic/Platt. Known-distribution pilot Table 6: Jev 0.595 / 0.130, 4B uncalibrated 0.628 / 0.213, 4B calibrated 0.550 / 0.089 (pooled). Calibrated 4B worse than Jev on Brier for selective disclosure and on ECE for daily evidence (§5.4).

## Cascade

42 of 111 Hard items (37.84%) routed to Atria-Dawn-Preview; 97/111 (87.39%) vs 82/111 (73.87%) small-only and 99/111 (89.19%) Atria-only; "one escalation operating point rather than an optimized routing policy" (§2, §5.5, Table 7). Threshold tau not reported.

## Robustness

Option-order reversal is built into the pilot (canonical and reversed variants, §4.2). No language, cardinality or option-name tests. Release supports 62 candidate symbols and up to 16 fields per request (§3.1). Causal ordering means fields can differ in context prefix; permutation invariance not enforced (§3.5).

## Code and data availability

Code https://github.com/InternLM/Intern-Decision; models https://huggingface.co/collections/internlm/intern-decision (abstract). Baseline adapters not included (App. A).

## Paper's own limitations

No matched-data ablation, so effects of joint scoring and model size are not isolated (§5.2); temperatures not comparably refitted for baselines (Table 4); Jev serving/transport conditions undocumented (Table 5); latency is a fixed short request, not long contexts or screenshots (§5.3); handoff time is estimated and a single operating point (Table 7); demos are qualitative (§6); generalization to large schemas is open (§7).
