# mohebifar2026onecodereviewbench

arXiv 2610.33389v1 (cs.SE), 24 Oct 2026. "OneCodeReviewBench: Typed Decisions for Code Review and Search." Authors Mohamad Mohebifar and Alex Bit, Codemod Inc. Affiliation type: industry. OpenAI Codex assisted with implementation and drafting; a Claude model gave pre-submission critique. (title block, AI Assistance Disclosure)

Study type: benchmark paper evaluating ten model-adapter systems, several of them typed decision models.

## Task and data
- 1,968 synthetic cases across 12 programming languages and YAML, from 161 templates (500 draft templates; 164 selected; 16 of 656 synthesis jobs failed on HTTP 500): 728 Boolean, 680 Choice, 560 Score (four ordered levels 0 to 3). Source-inventory questions account for 840 cases. Median fixture two files and 27 lines. (Sec. III, Table II)
- Fixtures, context and initial reference answers were generated by GPT-6-Sol; references are synthetic. One author reviewed 150 cases (50 per type); two paid engineers reviewed disjoint 50-case batches (100 cases with two responses: 85 agree, 7 differ, 8 second-reviewer abstentions). Full-packet reviewer matched 149 of 150 stored references. No final adjudicated key; 50 cases still need a second response; 65-case follow-up queue. Possible AI assistance during review was not logged. (Sec. III, III-A, V)
- A source audit found two template families with incomplete contracts (16 and 20 inputs; 36 repaired inputs archived separately); results are reported on the historical inputs, and a 1,932-case sensitivity analysis excludes both families. (Sec. IV-D)
- New synthetic items (2026), not in public training sets. The generator and one evaluated service (OpenAI Decisions) are from the same provider; authors note possible overlap, direction unknown. (Sec. V)

## Decision models
- Jev: jev-1.13.0 (TypeSafe hosted API). OpenAI Decisions: gpt-6-luna. Azure Decision-1: deployment decision-1, reporting microsoft-decision-1, run 23 October 2026 with raw requests, responses and UTC timestamps preserved; pinned backend revision unavailable. OpenJev (SemIf): local direct option scorer on Qwen3.5-4B. Laya SDK 0.3.6, revision 1c5edc17. Von SDK 1.1.1, revision d8bb5e07. Kev-0.8B/4B/9B v1.0 checkpoints, Kev-27B v2. Some historical timestamps unavailable. (Sec. IV-A, Table III)
- Adapters serialize the same files, context and criteria differently, so results are "model-adapter comparisons, not isolated architectures"; SemIf probabilities are converted from option scoring and "do not establish probability calibration". (Sec. IV-A)

## Comparators and tuning parity
All ten systems answer the same 1,968 identifiers under the same contracts, zero-shot, one run; no tuning described. Baselines: always-true Boolean (50.0), uniform Choice (24.7), in-sample level-2 Score constant (MAE 0.855). Source-tool comparators (raw symbol search on 586 cases; Python AST import resolver on 40 of 120 eligible, all 40 match) defined from public query rules before joining labels or predictions. (Sec. IV-A, IV-C)

## Results
Boolean balanced accuracy: OpenAI Decisions 81.3, Kev-27B 79.7, Jev 71.4, Azure 64.1, Kev-9B 56.5, Kev-4B 54.6, OpenJev 52.6, Von 50.9, Kev-0.8B 50.2, Laya 49.4. Choice accuracy: Kev-27B 76.8, Jev 71.6, OpenAI 68.2, Azure 63.4, Kev-9B 55.9. Score MAE: Kev-27B 0.367, Jev 0.403, Azure 0.430, OpenAI 0.516. Kev-27B minus Jev on Choice +5.15 (1.91 to 8.53, template-cluster bootstrap, 4,000 draws); Kev-27B minus Azure +13.38 (8.97 to 17.79); OpenAI versus Kev-27B on Boolean and Kev-27B versus Jev on Score intervals include zero; intervals unadjusted for multiplicity and lineage and condition on stored references. Reviewed 83-case subset: Kev-27B 89.0 / 81.5 / 0.228, Jev 74.1 / 77.8 / 0.239, Azure 72.8 / 55.6 / 0.301. Raw symbol search 34.5 Choice on 220 cases versus Jev 73.6; import resolver 100.0 versus Jev 57.1 (7 Choice cases). (Tables IV, VI, Sec. IV-A, IV-C)

## Cost and latency
Not measured; the paper says the runs "do not measure a matched latency/cost advantage" and lists it as future work.

## Calibration
Not evaluated. Boolean uses a 0.5 threshold; probabilities retained but no ECE or Brier. No post-hoc calibration.

## Cascade or escalation
Not tested; related cascade work is cited only as motivation.

## Robustness
Option order: shuffling criteria insertion order for Von changed 357, 336 and 350 of 680 Choice answers (49.4 to 52.5%) over three seeds, while eight easy Choice controls stayed correct. CPU versus MPS checks for Laya and Von preserved decisions (probability differences at most about 1e-4). 24 easy AST-checked controls: most systems 8/8; Von and Kev-0.8B 4/8 Boolean; Laya and Von high Score error. No language-level or option-name tests beyond order.

## Code and data
Version 20261023-v1 of the dataset and reproduction artifact on Zenodo (https://doi.org/10.5281/zenodo.23604731), CC BY 4.0 data, Apache-2.0 software; offline verifier reproduces tables without model calls. Individual reviewer responses withheld.

## Authors' limitations (Sec. V)
Reference review incomplete, quota sample gives no population error rate; synthetic fixtures with related constructions; generator and one evaluated service share a provider; selection for reviewer agreement; reviewer consent and ethics status not recorded; repository-scale transfer and matched latency and cost not evaluated; tokenizer and truncation traces unavailable.
