## Task and data
Retrieval within a known document: 11 configurations (BM25, OpenAI dense, BGE-M3 dense, hybrid RRF, hybrid plus BGE reranker, hybrid plus Jev / Decisions / Clef, and full scans with Jev / Decisions / Clef), common 500-token passages (75 overlap), five-passage limit, fixed generator gpt-4.1-mini-2025-04-14. (Sec. 2.1, Table 1)
Data: 396 QASPER questions (264 articles; 320 answerable, 76 unanswerable; human reference evidence) and 80 questions on eight OpenStax textbooks (four factual, three explanatory, three multi-section per book); book questions and references mostly generated by a frontier LLM (GPT-Astra) from relevant sections, supporting quotes checked against the source but no independent human validation. Separate development set of 60 QASPER training questions and 20 textbook questions; sources and references fixed before testing. (Sec. 2.1)
Answer evaluation on a fixed 200-question sample (100 answerable and 40 unanswerable QASPER, 60 book questions), RAGAS 0.4.3 Faithfulness and Answer Accuracy judged by gpt-6.1-sol, no human assessment. (Sec. 2.3)

## Decision models
Jev jev-1.13.0 (TypeSafe API); OpenAI Decisions API (gpt-6-luna); Cloudflare Clef 27B run locally (frozen revision ed3eed331870, BF16 on a shared NVIDIA GB10). All three process passages in windows with a 12,000-token request limit, up to ten candidates per window, successive rounds until five passages remain. Hybrid variants select from up to 50 hybrid candidates. API run dates not stated (latencies "with different dates and hardware conditions"). (Sec. 2.1, Table 3 caption)

## Comparators and tuning
Same passages, same five-passage limit, same candidate pool for rerankers; no tuning of any system reported. BGE rerankers on NVIDIA GB10 FP32. (Sec. 2.1, 2.2)

## Metrics and intervals
Evidence coverage EC@5 (source-token overlap with the best alternative evidence set; failed retrievals score zero), averaged within documents then across documents; paired differences and pointwise 95% intervals from 10,000 bootstrap resamples of whole documents, no multiplicity adjustment. Answer Accuracy and Faithfulness on 53 to 60 scored responses per method. (Sec. 2.2, 2.3, Tables 2, 5)

## Reference labels
QASPER: human-annotated evidence and answers. Books: LLM-generated questions and references with checked quotations. Answer scores: LLM judge against the reference.

## Test-data exposure
QASPER (2021) and OpenStax textbooks are public; authors note rephrasing does not rule out training-data overlap (Sec. 2.1).

## Key results
Books EC@5: Hybrid+Jev 94.1 [91.0, 97.2], Jev full scan 88.7 [81.2, 94.8], Hybrid+Decisions 87.4, Decisions full scan 76.6, Hybrid+Clef 91.2, Clef full scan 91.6, OpenAI dense 81.3 (Table 2). QASPER: Jev and Clef variants 96% or higher, OpenAI dense 90.4. Full scans lose evidence in reduction (Jev book scans 100% to 93.2%). Jev and Decisions failed on four and eight of 80 book scans. Answer Accuracy on books: Hybrid+Decisions 0.892, Decisions full scan 0.888, Jev full scan 0.874, Hybrid+Jev 0.864 (Table 5). (Sec. 3.1, 3.3)

## Cost and latency
Median book latency: Hybrid+Jev 1.72 s, Hybrid+Decisions 4.51 s, Hybrid+Clef 54.69 s; full scans 25.10 s, 63.36 s, 23.3 min. Latency reflects different deployments (hosted API versus local GPU, concurrency two for API calls). Projected API cost for 1,000 queries per book including preparation: OpenAI dense US$0.01351, Hybrid+Jev at least US$2.52, Jev full scan at least US$64.43, Hybrid+Decisions US$6.63, Decisions full scan at least US$155.85, Clef 0 API (local GPU unpriced); lower bounds arise from unknown consumption. (Sec. 3.2, Tables 3, 4)

## Calibration, cascade, robustness
No calibration analysis. No escalation cascade (the hybrid is a retrieve-then-select pipeline). Abstention on 40 unanswerable QASPER questions: the six decision-model configurations abstain in 11 to 14 cases versus 17 for OpenAI dense and 40 for the reference-context control. No option-name, option-order or language tests. (Sec. 3.3)

## Code and data
https://github.com/jrterven/jev-vs-rag (code, configurations, aggregate results).

## Authors' limitations (Sec. 4)
Retrieval within a known document with five passages and a 2,500-token context; eight textbooks and mostly model-generated references and automated answer scores; QASPER articles mostly fit the hybrid pool; latency reflects tested deployments; API charges exclude local compute.
